MODELAGEM DE BANCO DE DADOS — TRABALHO EM GRUPO

Dicionário de Dados

Sistema acadêmico da escola Microlins — derivado do modelo conceitual (DER) elaborado pelo grupo.

Domínio: processos escolares (matrícula, financeiro, professores, turmas) Origem: DER conceitual do grupo Versão: 1.0

1.Modelo conceitual

O modelo conceitual abaixo (Diagrama Entidade-Relacionamento) representa os processos de uma escola — a Microlins — cobrindo o cadastro de alunos, o atendimento realizado pela secretaria, a supervisão de professores, a oferta de cursos organizados em turmas, o controle de horário de funcionamento e o registro financeiro das matrículas.

Entidades identificadas: ALUNO, SECRETARIA, PROFESSOR, CURSO, TURMA, HORARIO_FUNCIONAMENTO, FINANCEIRO, MATRICULA.

2.Convenções deste dicionário

Os atributos são listados exatamente como definidos no DER conceitual. Os tipos físicos indicados a seguir são sugestões de implementação (nível lógico), usadas apenas para tornar o dicionário mais completo — o DER em si não define tipos de dado.

PK — chave primária da entidade
(min,max) — cardinalidade mínima e máxima do relacionamento
INT — número inteiro
VARCHAR(n) — texto de tamanho variável, limite n
DATE — data (dia/mês/ano)
TIME — horário (hora:minuto)
DECIMAL(p,s) — número decimal com p dígitos, s casas

4.Dicionário de relacionamentos

Cardinalidades exatamente como definidas no DER conceitual, no formato (mínimo, máximo) ao lado de cada entidade participante.

Relacionamentos do modelo
RelacionamentoEntidades envolvidasCardinalidadeDescrição
ATENDESECRETARIA ↔ ALUNOSECRETARIA (1,1) — ALUNO (0,N)A secretaria atende os alunos.
SUPERVISIONASECRETARIA ↔ PROFESSORSECRETARIA (1,1) — PROFESSOR (1,N)A secretaria supervisiona os professores.
GERASECRETARIA ↔ MATRICULASECRETARIA (1,1) — MATRICULA (0,N)A secretaria gera as matrículas.
LECIONAPROFESSOR ↔ CURSOPROFESSOR (1,1) — CURSO (0,N)O professor leciona os cursos.
CONTÉMCURSO ↔ TURMACURSO (1,1) — TURMA (1,N)O curso contém as turmas.
RESTRINGETURMA ↔ HORARIO_FUNCIONAMENTOTURMA (1,N) — HORARIO_FUNCIONAMENTO (1,1)O horário de funcionamento restringe as turmas.
INCLUI (1)ALUNO ↔ MATRICULAALUNO (1,N) — MATRICULA (1,1)A matrícula inclui o aluno.
INCLUI (2)FINANCEIRO ↔ MATRICULAFINANCEIRO (1,1) — MATRICULA (1,N)O financeiro inclui as matrículas.
INCLUI (3)MATRICULA ↔ CURSO ↔ TURMAMATRICULA (1,N) — CURSO (1,1) — TURMA (não especificada)Relacionamento ternário: a matrícula inclui um curso, cursado em uma turma específica.
Há três relacionamentos distintos nomeados INCLUI no DER — foram numerados (1), (2) e (3) apenas para diferenciação neste dicionário. No relacionamento ternário INCLUI (3), a cardinalidade do lado de TURMA não foi indicada no diagrama original.
